# Green Home Score and Retrofit Recommendation Engine

Setup and run instructions. Team 319, Megathon X: Singularity, Lloyds Problem Statement 2.

## Requirements

- Python 3.10 or newer (developed and tested on Python 3.12)
- The packages in `requirements.txt`
- Optional: a Google AI Studio (Gemini) API key for the AI explanation box. Without a key the app still runs and shows a plain-text explanation instead.

## Install

```
pip install -r requirements.txt
```

## Run the app

From the folder that contains `app.py`:

```
streamlit run app.py
```

Open the address that Streamlit prints (usually http://localhost:8501).

On first run the app generates the synthetic data into the `data/` folder. Use the "Random seed" box in the sidebar and press "Generate dataset" to recreate a dataset. The same seed gives the same data.

## Train the energy-use model

Scroll to the "Energy-use model" section of the app and press "Train / refresh model". Results are written to `reports/` and the model to `models/`.

You can also run it from the command line:

```
python ml_model.py
```

## Turn on the AI explanation (optional)

Set these environment variables before starting the app. Do not put your key in any file.

Mac or Linux:

```
export LLM_PROVIDER=gemini
export LLM_API_KEY=your-key-here
export LLM_MODEL=gemini-3-flash-preview
streamlit run app.py
```

Windows PowerShell:

```
$env:LLM_PROVIDER="gemini"
$env:LLM_API_KEY="your-key-here"
$env:LLM_MODEL="gemini-3-flash-preview"
streamlit run app.py
```

On Replit, add the same three names under Tools, then Secrets, and restart the app.

If the model name stops working, set `LLM_MODEL` to a current Gemini model name from Google AI Studio.

## Run the tests

None of the tests need an API key.

```
python test_scoring.py
python test_retrofit.py
python test_ml_model.py
python test_llm_explain.py
```

Each should finish with a passing message.

## Data and model files

No externally hosted datasets or model weights are required. All data is synthetic and is generated by `dataset.py`. The trained model in `models/` can be recreated with the training step above. `data/emissions_factors.csv` and `data/retrofit_catalogue.csv` are included in the repository.
